
# Inventario del problema 

Todo lo que encontré lo meto tal cual en esta tabla, tratando de relacionar cada acción con quien la realiza y con los objetos o datos que necesita para poder ejecutarse: 

| Elemento               | Tipo            | Atributos / datos                                                        | Acciones                                              | ¿Lo necesito?  | ¿Por qué?                                                                                                                  |
| ---------------------- | --------------- | ------------------------------------------------------------------------ | ----------------------------------------------------- | -------------- | ---------------------------------------------------------------------------------------------------------------------------|
| Banco                  | Entidad         | Cajeros, clientes, registros                                             | Registrar información, administrar cajeros            | No             | El problema puede resolverse sin representar al banco como una entidad dentro del programa.                                |
| Cliente                | Actor           | Nombre, apellido, DNI, domicilio, teléfono, correo, número de cliente    | Insertar tarjeta, ingresar PIN, seleccionar operación | No             | El cliente interviene como usuario del sistema, pero sus datos personales no son necesarios para ejecutar las operaciones. |
| Cajero automático      | Entidad         | Identificador, ubicación, efectivo disponible, tarjetas aceptadas, color | Permitir operaciones, entregar efectivo               | Sí             | Se necesita porque interviene en las operaciones y dispone de efectivo, aunque no todos sus atributos son necesarios.      |
| Sucursal               | Entidad         | Fecha de pintura                                                         | Contener cajeros                                      | No             | La sucursal no participa en las operaciones que debe resolver el programa.                                                 |
| Cuenta bancaria        | Entidad         | Número de cuenta, saldo                                                  | Consultar saldo, debitar, actualizar saldo            | Sí             | El saldo se consulta y modifica sobre la cuenta.                                                                           |
| Tarjeta                | Entidad         | Estado, PIN, intentos fallidos                                           | Validarse, permitir acceso, bloquearse                | Sí             | Es necesaria para controlar el acceso mediante su estado, el PIN y los intentos fallidos.                                  |
| Operación              | Evento/Registro | Tipo, monto, fecha, hora, cajero utilizado                               | Registrarse                                           | Sí             | Cada operación completada debe quedar registrada con los datos indicados en el problema.                                   |
| Consulta de saldo      | Operación       | Cuenta, saldo                                                            | Consultar y mostrar saldo                             | Sí             | Es una de las operaciones que el sistema debe permitir.                                                                    |
| Extracción             | Operación       | Cuenta, monto                                                            | Validar, descontar saldo, descontar efectivo          | Sí             | Es una de las operaciones principales y requiere verificar saldo, monto y efectivo disponible.                             |
| Transferencia          | Operación       | Cuenta, CBU, monto                                                       | Validar CBU, verificar saldo, descontar monto         | Sí             | Es una de las operaciones que debe poder realizarse y requiere controlar el saldo disponible.                              |
| PIN correcto           | Atributo        | Valor del PIN                                                            | —                                                     | Sí             | Es necesario para comparar el PIN ingresado y decidir si se permite el acceso.                                             |
| Saldo                  | Atributo        | Monto disponible                                                         | —                                                     | Sí             | Se consulta y se modifica según la operación realizada.                                                                    |
| Estado de tarjeta      | Atributo        | Habilitada / bloqueada                                                   | —                                                     | Sí             | Permite determinar si la tarjeta puede utilizarse.                                                                         |
| Límite de extracción   | Regla           | Máximo $300.000                                                          | Restringir extracción                                 | Sí             | El problema establece expresamente que una extracción no puede superar ese monto.                                          |
| Múltiplo de extracción | Regla           | $1.000                                                                   | Restringir extracción                                 | Sí             | El problema establece que el monto extraído debe ser múltiplo de $1.000.                                                   |
| Bloqueo por PIN        | Regla           | Tres errores consecutivos                                                | Bloquear tarjeta                                      | Sí             | El problema establece que la tarjeta debe bloquearse después de tres PIN incorrectos consecutivos.                         |
| Monitor                | Entidad         | Marca                                                                    | —                                                     | No             | La marca del monitor no interviene en ninguna operación ni validación del sistema.                                         |


Con esta tabla nos podemos empezar a preguntar qué es lo importante de todo esto. Es decir, ¿cuáles de estos elementos necesito representar para resolver el problema? (Resolver el problema sería hacer un programa que represente todo el sistema creo...)
